- C1–C9: exhaustive frequency-120 identity and arc index; bounded dense/sparse state; explicit optional C4 compute adapter; bounded synchronous scheduler; resource characterization; exact deterministic distributed composition; clean-source replay and stable API consumer.
- Public source layout reuses seven existing kernel/geometry files instead of vendoring a second copy. The five newly published computational modules retain their frozen bytes.
